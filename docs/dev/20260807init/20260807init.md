# 腾讯元宝 OpenAI 代理 - 实施规划

## 阶段一：重写 proxy.js（新版）
- 基于旧版 proxy(1).js 核心逻辑，整合 admin.html 需要的管理功能
- 新增功能：
  1. 配置热加载（fs.watchFile 监听 config.json 变化）
  2. 管理 API：GET/POST /api/config, GET /api/stats
  3. Function Call 适配（tools 参数检测 + system prompt 注入 + <tool_call> 解析）
  4. 并发控制（超过 maxConcurrent 返回 429）
  5. 请求超时 & 重试（可配置）
  6. CORS 白名单（从 config.json 读取）
  7. 日志级别控制
  8. Keep-Alive TLS 连接池
- 输出文件：proxy.js

## 阶段二：接入 new-api
1. 启动 yuanbao2api：node proxy.js
2. 在 new-api 管理后台添加渠道：
   - 类型：OpenAI
   - Base URL：http://localhost:8080/v1
   - Models：yuanbao,hunyuan,tencent-yuanbao

## 阶段三：通过 cc-switch 配置到 codex/opencode
1. 在 new-api 获取 API Key
2. 在 cc-switch 添加自定义 provider，指向 new-api
3. 在 codex/opencode 中选择使用
