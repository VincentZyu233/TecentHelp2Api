适配原理说明

function call 适配的完整工作流程

1. 请求转换

OpenAI tools 定义 → 转换为自然语言描述 → 注入到 query 开头

2. 模型推理

元宝按注入的指令格式输出，如：<tool_call>{"name":"get_weather","arguments":{"city":"深圳"}}</tool_call>

3. 输出解析

非流式：完整输出后解析标记 → 返回 OpenAI tool_calls 格式

流式：缓冲前 N 字符检测标记 → 命中则返回 tool_calls chunk → 未命中则透传

4. 多轮对话

tool 返回结果会被转为自然语言拼入 query，支持连续多轮工具调用
